# Rosa v2.11.14 — global glass and live Reception rebuild

- Corrected the live v2.8 Reception renderer rather than styling the unused legacy inbox markup.
- Reused the Gmail-like mobile message row structure with sender avatars, sender/time, subject and two-line snippet.
- Mobile starts on the inbox list, tapping a message opens a full-screen thread, and Back returns to inbox.
- Added mobile search, compose, bottom navigation and wired search/compose/tasks to existing app actions.
- Added a unified rounded translucent glass system, removed dark border colors, and styled the desktop settings/notification drawers as glass surfaces.
- Increased visual contrast for selected navigation using Rosa yellow.

Validation: JavaScript syntax check and ZIP integrity check passed. Live browser and physical phone visual testing have not been performed.
