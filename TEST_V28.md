# Rosa V2.8 quick test

1. Run `SETUP_ROSA_AI.bat` if you want the optional Luna fallback in this new folder.
2. Run `START_ROSA.bat` and log in as the owner.
3. Open **Reception**.
4. In **Inbox**, analyze a guest message and press **Draft smart reply**. Short structured messages should remain Local; nuanced long messages may use Luna.
5. Open **Scheduled**. The demo includes a clearly labelled Rosa preview. Nothing has been sent externally.
6. Open **Automations** and press **Run Rosa scheduler** while in OBSERVE. New items should appear as Preview.
7. Switch to ASSIST and run it on a fresh/reset demo. Communication items should require approval and generate notifications.
8. Use **Simulate send** only to test the workflow; it does not contact any guest channel.
