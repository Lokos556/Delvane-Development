# Delvane applications

This directory belongs to the existing Delvane-Development Git repository.
There is no separate application repository or nested Git checkout.

- `delvane_business/`: Flutter workspace for Windows, Android, iOS, and macOS.
- The existing Python/FastAPI backend remains at the repository root. Its
  entry points, scripts, database paths, and integrations have not moved.

Run Flutter commands from `apps/delvane_business`, not the repository root.
See the application's README for mock-mode boundaries, architecture and checks.
