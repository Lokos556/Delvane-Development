## Export and privacy contract

`delvane.ntak.evidence`, format_version1, is canonical UTF-8 JSON with stable ordering and SHA256 response header. It includes the selected property's/environment's related reporting versions, redacted source facts, immutable snapshot and event hashes, delivery attempts, original and subsequent processing references, structured diagnostics, timestamps, correction lineage and operator recovery/replay provenance. Viewing/exporting does not mutate facts or delivery state. Export uses a consistent database transaction; repeated export without changed reporting facts/state produces identical bytes. Access audit entries are deliberately excluded from the package so an export does not change its own content.

No raw XML, free-text returned errors, raw reader/manual identity sources, document scans, birth facts, guest hashes/identifiers, credential references, private keys, tokens or salts are exported. Only schema-declared source fields are considered; identity fields and unnecessary free text are omitted. Unknown keys and invalid dates are hidden. Complete in-contract protocol bytes stay encrypted on the server, not in general diagnostics. Oversized responses beyond the existing8MiB contract limit retain a hash/size marker rather than unbounded content. Responses missing because of timeout/crash remain explicitly unknown.

Local preparation, possible transmission, receipt, final processing state and operator-supplied processing reference are distinct records. All injected adapters are labelled offline; `official_acceptance_confirmed` and `transmission_enabled` remain false, including when a mock returns TELJESEN_SIKERES. The evidence is the exact unsigned adapter input currently used by offline tests; final signed-wire capture must be connected to the resolved Task18 adapter later. No signing profile was invented.
