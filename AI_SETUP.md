# Optional GPT-5.6 Luna setup — Rosa V2.8.3

Rosa remains **local-first**. Exact property facts, operations lookups, missing facts, structured guest-message extraction, guest memory and governed actions stay local where deterministic handling is better. Luna is used only where freer language reasoning adds value.

Run `SETUP_ROSA_AI.bat`, paste the project API key when prompted, and wait for `CONNECTED — Luna replied: OK`. The key is stored only in `.env.local` and is intentionally excluded from the ZIP.
