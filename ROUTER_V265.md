# V2.6.5 routing contract

1. **LOCAL** — clear out-of-scope/general-knowledge probes; no AI call.
2. **ACTION ENGINE** — supported governed writes; deterministic only.
3. **LUNA** — judgment, prioritization, explanation and synthesis.
4. **DATABASE** — exact stored facts.
5. **OPERATIONS** — exact operational lookups/counts/status.
6. **NOT RECORDED** — objective Casa Rosa fact requested but no supported stored value exists.
7. **LUNA fallback** — remaining business-language requests when Luna is configured.

The important negative rule is: **absence of data is itself an answer**. Missing property facts do not justify an LLM call.
