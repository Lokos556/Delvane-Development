# Rosa V2.6.3 — Conversation-first Intelligence

V2.6.3 makes Rosa AI the primary working surface instead of a small card inside the Intelligence dashboard.

## Layout
- Dedicated full-height intelligence workspace with no page-level chat scrolling.
- Left conversation history rail with persistent recent chats and New chat.
- Large central chat surface with a fixed composer, auto-growing textarea and scrollable message history.
- Right live-context rail containing the briefing, metrics, owner decisions and exceptions. Existing intelligence information was moved here, not removed.
- Search and operating-mode controls moved into the Rosa header.
- Suggested prompts remain available directly above the composer.
- Tablet/mobile: History and Context become slide-in drawers while chat stays full-width.

## Design
The old-money Rosa visual language is preserved, but the message experience now follows familiar commercial assistant conventions: assistant responses read as clean document-style messages, user messages are compact bubbles, conversation history is immediately accessible, and the input is always reachable.

## Localization
All new V2.6.3 interface copy is provided for all 18 currently supported UI languages.
